# KOF Online Launcher

Primeira fundação do launcher do KOF 98 Custom.

- O jogo original é referenciado, nunca alterado.
- `Jogar offline` inicia o `mugen.exe` com o diretório de trabalho correto.
- O caminho pode ser escolhido em Configurações.
- O lobby online será implementado como serviço separado.

## Compilar

```powershell
dotnet build -c Release
```
